# Onboarding de beta

## Objetivo

Garantir que o cliente beta consiga configurar e validar uma campanha em menos de 30 minutos, com o mínimo de atrito.

## Sessão inicial (10 minutos)

- confirmar o objetivo da campanha
- explicar o fluxo: comentário → DM → link rastreado → relatório
- revisar a palavra-chave e o CTA
- confirmar a URL final e o critério de conversão

## Setup técnico (10 minutos)

- conectar conta Instagram
- criar workspace e selecionar conta
- criar campanha
- definir palavras-chave e mensagem DM
- inserir link rastreado
- verificar se o link abre corretamente

## Validação funcional (10 minutos)

- testar comentário com trigger
- confirmar resposta DM
- confirmar clique e redirecionamento
- confirmar métricas e relatório compartilhável

## Perguntas para coletar ao fim

- a proposta ficou clara?
- o cliente entende o que o sistema faz em 10 segundos?
- o fluxo de CTA está bom?
- o relatório faz sentido para apresentar ao cliente?
- o que faltou para a operação diária?

## Observações para registrar

- tempo até primeiro setup concluído
- tempo até primeiro clique registrado
- qualidade do CTA
- atrito de onboarding
- feedback sobre relatórios
- feedback sobre clareza de produto

## Critério de sucesso

A sessão de onboarding é considerada bem-sucedida quando:

- o cliente consegue criar e testar a campanha sozinho
- a primeira resposta DM é entregue
- pelo menos um clique é registrado
- o relatório público é acessado e entendido

## Tarefas pós-onboarding

- registrar o feedback em documento compartilhado
- priorizar 3 correções mais importantes
- ajustar a landing page e uso de CTA se necessário
- preparar a próxima rodada com base nos aprendizados
