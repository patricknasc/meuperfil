# Beta privada: rollout operacional

## Objetivo

Validar o fluxo completo de campanha com clientes reais em um grupo pequeno, antes de abrir mais volume ou público.

## Critério de sucesso do beta

O beta é válido quando um cliente consegue:

1. criar uma campanha de Instagram
2. responder comentários com DM automatizado
3. incluir um link rastreado
4. receber cliques e registrar conversão
5. abrir o relatório compartilhável e entender desempenho

## Primeira rodada de beta

### Alvo
- 3 a 5 contas ou agências com necessidade real de campanhas de Instagram
- perfis com público engajado e CTA clara
- uso de comentários com palavras-chave e ofertas simples

### Oferta
- onboarding guiado em 30 minutos
- acesso beta completo por 2 semanas
- feedback direto via canal de suporte
- prioridade de roadmap para relatórios e automações
- proposta de preço fundador ou condição especial para primeira rodada

## Checklist do onboarding

### Antes do setup
- [ ] confirmar quem é o dono do workspace
- [ ] confirmar o Instagram Business/Creator a ser conectado
- [ ] confirmar a URL do post alvo
- [ ] confirmar 3 a 5 palavras-chave de trigger
- [ ] confirmar oferta principal, CTA e link rastreado
- [ ] confirmar o objetivo da campanha (lead, waitlist, compra, agenda, etc.)

### Setup na plataforma
- [ ] criar workspace e convidar o cliente/owner
- [ ] conectar a conta do Instagram
- [ ] criar campanha com nome, objetivo e palavras-chave
- [ ] definir mensagem DM
- [ ] adicionar link rastreado de destino
- [ ] ativar relatório compartilhável
- [ ] verificar o link rastreado com um clique de teste

### Validação do fluxo
- [ ] publicar ou selecionar um post para testar
- [ ] enviar comentário com palavra-chave e verificar resposta DM
- [ ] confirmar que o link rastreado redireciona corretamente
- [ ] verificar registro de click em analytics/report
- [ ] abrir a URL do relatório compartilhável

### Feedback
- [ ] coletar elogios, atritos e objeções em 15 minutos
- [ ] registrar se o CTA foi claro
- [ ] identificar o que faltou para uso real: relatórios, templates, onboarding, automação

## Métricas de beta

- tempo para primeiro campanha funcionando
- tempo para primeiro clique rastreado
- taxa de sucesso de comentário → DM
- taxa de clique no link
- tempo para gerar relatório público
- feedback qualitativo do cliente sobre clareza e valor

## Critérios para avançar

A plataforma está pronta para ampliar a beta quando:

- o fluxo comentário → DM → link → clique funciona consistentemente
- o relatório público é útil e legível
- onboarding leva menos de 30 minutos
- o cliente entende o valor sem explicar a lógica do produto

## Próxima execução

1. selecionar 3 primeiros clientes beta
2. enviar convite com onboarding guiado
3. rodar campanha de teste em cada um
4. registrar feedback em 48h
5. ajustar CTA, relatório e onboarding
6. liberar próxima rodada para mais usuários

## Triggers para suporte

- DM não enviada
- palavra-chave não matcha
- link não rastreia clique
- relatório público não aparece
- cliente não consegue conectar conta Instagram

## Tópicos de feedback a coletar

- “Qual parte ficou mais confusa?”
- “Qual ação você quer que o sistema provoque?”
- “Seu cliente entende melhor a oferta com link rastreado?”
- “O relatório ajudaria a fechar o próximo cliente?”
- “O que falta para você usar isso todos os dias?”
